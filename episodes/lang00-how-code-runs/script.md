## Voice-over

Your computer doesn't understand Python, or C, or any language you write.
It only understands numbers. Ones and zeros.
Each pattern tells the processor one tiny thing: add, compare, jump.
Nobody wants to write that. So we write code for humans, and translate it.
A compiler translates the whole program before it runs. Like translating a book once. That's C.
An interpreter translates as it runs, line by line, like a live interpreter. Flexible, but slower. That's Python.
And some do both: compile to a middle language, then a virtual machine runs it. That's Java and C#.
Every language in this series is one of these three.
