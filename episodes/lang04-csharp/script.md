# Languages 04: C#

Series: "How languages actually work" (under 60 s). Look and props: engine/series-languages.js.
Facts: announced by Microsoft in 2000 (1.0 shipped with .NET in 2002), lead designer Anders Hejlsberg
(later lead architect of TypeScript). Name: the sharp sign reads as four plus signs (C++ ++).
csc/Roslyn -> IL (Intermediate Language) in a .dll -> the .NET runtime (CLR) JIT-compiles it to machine
code. C# 5 (2012) made async/await mainstream; JavaScript, Python and Rust adopted the same keywords.
Unity scripts are C# (Among Us, Hollow Knight, Pokémon GO are Unity games). ASP.NET Core backends.

## Voice-over

Among Us, Hollow Knight and Pokémon GO have one thing in common: this language.
It's C sharp. Microsoft, 2000. Designed by Anders Hejlsberg, who later created TypeScript too.
The name is a joke: the sharp sign is four plus signs. C plus plus, plus plus.
Like Java, it compiles to an in-between language called IL. On your device, the dot NET runtime turns it into machine code.
Its superpower: async and await. Your app waits for the internet without freezing.
JavaScript, Python and Rust liked it so much, they copied it.
Today it runs Unity games, Windows apps, and huge web backends.
Next: Python. The language that reads almost like English.
