# Languages 01: C

Series: "How languages actually work" (under 60 s). Look and props: engine/series-languages.js.
Facts: Dennis Ritchie, Bell Labs, 1972, to rewrite Unix. Linux (Android's kernel) is mostly C.
~70 % of serious security bugs are memory-safety bugs (Microsoft, 2019; Chromium, 2020).
"hello, world" was made famous by Kernighan & Ritchie's "The C Programming Language" (1978).

## Voice-over

This language is fifty years old, and you used it today.
It's C. Born in 1972 at Bell Labs, to rewrite an operating system: Unix.
C compiles straight to machine code. Nothing in between.
So it's fast, and it runs almost everywhere.
Android's Linux kernel? Mostly C. Your car, your router, your microwave? Probably C.
Its superpower is pointers: you work with memory addresses directly.
But C trusts you completely. Write past the end of an array, and nothing stops you.
Memory bugs like that cause around seventy percent of serious security bugs in Chrome and Windows.
Hello, world: the most famous first program ever. A C book made it famous in 1978.
