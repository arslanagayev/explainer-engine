# Languages 02: C++

Series: "How languages actually work" (under 60 s). Look and props: engine/series-languages.js.
Facts: Bjarne Stroustrup started "C with Classes" at Bell Labs in 1979, renamed C++ in 1983.
`++` is C's increment operator. Unreal Engine, Chrome and Photoshop are written in C++.
The ISO C++ standard runs to roughly 2,000 pages.

## Voice-over

Every big game you've played was probably built on this language.
It's C plus plus. In C, plus plus means "add one". So the name is a joke: C, one better.
Bjarne Stroustrup built it at Bell Labs, starting in 1979.
His idea: keep C's speed, but add classes.
A class bundles data and code into one object: a Player with health and a takeDamage function.
And it still compiles straight to machine code. Abstractions with no runtime cost.
And objects clean up after themselves: when one goes away, its destructor frees its memory.
That's why Unreal Engine, Chrome and Photoshop run on C plus plus.
The catch? It's huge. Even experts say nobody knows all of C plus plus.
